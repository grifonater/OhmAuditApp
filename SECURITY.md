# Security policy

OhmAudit contains multi-tenant customer, site, asset, inspection, and report data. Security issues must not be posted in a public issue or discussion.

Report a suspected vulnerability privately to the repository owner or maintainers. Include the affected area, reproduction steps, likely impact, and any suggested remediation. Do not include production credentials, personal data, customer documents, or destructive proof-of-concept data.

Until a public disclosure process is established, security reports and fixes should remain private. Rotate any credential immediately if it may have been exposed, even when it has already been removed from source control.
