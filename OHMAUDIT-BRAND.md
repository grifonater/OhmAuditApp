# Ohm Audit brand system

## Brand character

OhmAudit should feel dependable, precise and operationally calm. The interface uses deep navy for permanent navigation, clear blue for navigation and information, and a focused amber for primary actions. This makes the product feel like a mature compliance workspace while retaining an electrical-energy cue.

## Usage rules

- Use Action Amber for the single primary action on a page; avoid multiple competing primary buttons.
- Use Interface Blue for links, selection, focus and data visualisation—not as a competing primary action.
- Use semantic text or icons alongside colour so status never depends on colour alone.
- Contractor-selected brand colours belong to generated documents and branding previews. They do not replace the core Ohm Audit application navigation colours.
- Maintain WCAG AA contrast for text and keep a visible Interface Blue keyboard focus ring.
