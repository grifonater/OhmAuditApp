# Solar PV module

Solar uses authoritative relationships: Solar System → Array/Roof Area → Inverter → MPPT → String. Interactive diagrams are generated views, never the primary data model, and have a table/tree accessibility fallback.

The scaffold allows DC/AC characteristics, measurements, photos, and defects without inventing regulatory limits. Future raw imports pass through a provider-neutral InspectionDataImporter, retain original files, and require mapping review and validation.
